##  Erklärung
Attribute sind die **Eigenschaften eines Objekts**.

-> Sie speichern Daten.

---

## 🎮 Beispiel

```java
public class Spieler {
    String name;
    int leben;
}
```

#### Erklärung Code
-  `String name` -> Text
- `int leben` -> Zahl
- `name` und `leben` sind **Attribute**

---
## 💡 Merksatz

Attribute = Daten eines Objekts
