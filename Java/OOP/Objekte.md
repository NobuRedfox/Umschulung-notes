##  Erklärung
Ein Objekt ist eine **konkrete Instanz einer Klasse**.

-> Während die Klasse nur der Bauplan ist,
ist das Objekt das **echte Ding im Programm**.

---

##  Beispiel (Spiel)

```java
Spieler s1 = new Spieler();
```

#### Erklärung Code
- `Spieler` → Klasse (Bauplan)
- `s1` → Name des Objekts (der Klasse `Spieler`)
- `new Spieler()` → erstellt ein neues Objekt

---
##  Werte setzen

```java
s1.name = "Nobu";
s1.leben = 100;
```

-> Jetzt hat dein Objekt echte Daten

---
## ⚠️ Häufige Fehler

- ❌ Objekt ohne `new` erstellen
- ❌ Klasse und Objekt verwechseln
