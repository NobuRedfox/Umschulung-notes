
>[!info]
>## Erklärung
>
>OOP steht für **Objektorientierte Programmierung**.
>
>Dabei wird ein Programm aus Objekten und Klassen aufgebaut.

---

# Definition

Die OOP ist ein Programmierparadigma.

Programme werden dabei in:
- Klassen
- Objekte

unterteilt.

Objekte besitzen:
- Eigenschaften (**Attribute**)
- Funktionen (**Methoden**)

---

# Grundidee

In der OOP wird versucht, reale Dinge als Objekte darzustellen.

Beispiele:
- Spieler
- Autos
- Tiere
- Gegner

Jedes Objekt besitzt eigene Daten und Funktionen.

---

# Beispiel

```java
public class Spieler {

    String name;
    int leben;

    public void anzeigen() {
        System.out.println(name);
    }
}
```

Die Klasse besitzt:
- Attribute
- Methoden

---

# Die 4 Grundprinzipien

## Kapselung
Daten werden geschützt und kontrolliert genutzt.

---

## Vererbung
Klassen können Eigenschaften anderer Klassen übernehmen.

---

## Polymorphie
Methoden können unterschiedlich arbeiten.

---

## Abstraktion
Wichtige Dinge werden gezeigt, unwichtige versteckt.

---

# Vorteile

OOP sorgt für:
- übersichtlichen Code
- bessere Wartbarkeit
- Wiederverwendbarkeit
- einfachere Erweiterung

---

# Nachteile

Mögliche Nachteile:
- komplexer für Anfänger
- manchmal mehr Code notwendig
