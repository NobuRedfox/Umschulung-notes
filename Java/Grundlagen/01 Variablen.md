## Erklärung

Eine Variable ist ein **Behälter für Daten**.
#### Beispiel:
```java
int zahl = 10;             // ganze Zahl
double preis = 9.99;       // Kommazahl
String name = "Nobu";      // text
boolean istFertig = true;  // wahr oder falsch
```

#### Wert ändern
```java
int zahl = 10;
zahl = 20;

System.out.println(zahl); // 20
```


### Übungen
#### Übung 1
Erstelle eine Variable **alter** mit dem Wert 25 und gib sie aus.
```java
int alter = 25;
System.out.println(alter);
```

#### Übung 2
Erstelle eine Variable **preis** mit dem Wert 19,99 und gib sie aus.
```java
double preis = 19.99;
System.out.println(preis);
```

#### Übung 3
Erstelle eine Variable **name** mit deinem Namen und gib sie aus.
```java
String name = "Nobu";
System.out.println(name);
```

#### Übung 4
Erstelle eine Variable **istFertig** und setze sie auf **false**.
```java
boolean istFertig = false;
System.out.println(istFertig);
```
