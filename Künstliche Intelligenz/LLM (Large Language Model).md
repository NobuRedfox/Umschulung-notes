
> [!important]
> Ein LLM ist ein großes neuronales Netzwerk, das Text verarbeiten und erzeugen kann.

## Ablauf

1. Text → [[Token]]
2. Tokens → [[Embeddings]]
3. Verarbeitung im Netzwerk
4. Vorhersage des nächsten Wortes

## Eigenschaften

- kann Texte generieren
- versteht Sprache
- basiert auf Wahrscheinlichkeiten

## Grundlage

- neuronale Netze
- Gewichte
- Gradientenabstieg
