> [!info]
> ## Bedeutung
> Ethernet = kabelgebundene Netzwerkverbindung

---

# Definition

[[Ethernet]] ist eine Technik zur kabelgebundenen Datenübertragung in Netzwerken.

Sie ermöglicht die Kommunikation zwischen:
- Computern
- Routern
- Switches
- Servern

---

# Aufgabe

[[Ethernet]]:
- verbindet Geräte in Netzwerken
- überträgt Daten
- ermöglicht Internetzugriff
- sorgt für stabile Netzwerkverbindungen

---

# Verbindung zur Hardware

Ethernet arbeitet zusammen mit:
- [[NIC]]
- Router
- Switch
- Netzwerkkabel

---

# Netzwerkkabel

Für Ethernet werden meist sogenannte:
- RJ45-Kabel

verwendet.

Diese Kabel besitzen acht Kontakte.

---

# Eigenschaften

Ethernet bietet:
- stabile Verbindung
- hohe Geschwindigkeit
- geringe Latenz
- zuverlässige Datenübertragung

---

# Geschwindigkeit

Typische Ethernet-Geschwindigkeiten:

| Standard | Geschwindigkeit |
|---|---|
| Fast Ethernet | 100 Mbit/s |
| Gigabit Ethernet | 1 Gbit/s |
| 10-Gigabit Ethernet | 10 Gbit/s |

---

# Vorteile

Ethernet bietet:
- stabile Verbindung
- hohe Geschwindigkeit
- geringe Störungen
- geringe Verzögerung

Besonders wichtig für:
- Gaming
- Server
- große Downloads

---

# Nachteile

Ethernet:
- benötigt Kabel
- ist weniger flexibel als WLAN
- benötigt oft zusätzliche Hardware

---

# Ethernet vs WLAN

## Ethernet

- kabelgebunden
- stabiler
- meist schneller
- geringere Latenz

---

## WLAN

- kabellos
- flexibler
- einfacher mobil nutzbar

---

# Einsatzgebiete

Ethernet wird genutzt für:
- Heimnetzwerke
- Unternehmen
- Rechenzentren
- Gaming-PCs
- Server

---

# Switches

In größeren Netzwerken werden oft:
- Switches

verwendet.

Sie verbinden mehrere Geräte miteinander.

---

# MAC-Adresse

Jede Netzwerkkarte besitzt eine:
- MAC-Adresse

Diese dient zur eindeutigen Identifikation im Netzwerk.
