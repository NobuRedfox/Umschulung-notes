>[!info]
> ## Erklärung
> Flags sind Optionen für Befehle.
> Sie bestimmen, **wie** ein Befehl ausgeführt wird.

---

## Allgemein wichtige Flags

- -r → recursive  
  (Ordner + Inhalt verarbeiten)

- -f → force  
  (ohne Nachfrage ausführen)

- -i → interactive  
  (fragt vor Aktion nach)

- -v → verbose  
  (zeigt an, was passiert)

---

##  ls (list)

- -l → long (Details anzeigen)
- -a → all (versteckte Dateien anzeigen)
- -h → human (lesbare Größen)
- -t → time (nach Datum sortieren)

---
##  rm (remove)

- -r → Ordner löschen
- -f → ohne Nachfrage löschen

---
##  cp (copy)

- -r → Ordner kopieren
- -v → zeigt Kopiervorgang

---
## mv (move)

- -v → zeigt Verschieben an

---
## grep (search)

- -i → ignore case
- -r → rekursiv suchen

---
## git

- -m → message
- -a → alle Änderungen
- -u → upstream setzen
