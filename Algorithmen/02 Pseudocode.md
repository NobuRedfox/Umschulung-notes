## Definition

Pseudocode ist eine vereinfachte Beschreibung eines Algorithmus.

Er ähnelt einer Programmiersprache, besitzt aber keine feste Syntax.

Pseudocode dient dazu, die Logik eines Algorithmus verständlich darzustellen, bevor er in einer Programmiersprache umgesetzt wird.

---

## Eigenschaften

Pseudocode:

- ist leicht lesbar
- ist sprachunabhängig
- konzentriert sich auf die Logik
- kann von Menschen einfach verstanden werden
- muss keine Programmiersyntax einhalten

---

## Warum verwendet man Pseudocode?

Bevor ein Programm geschrieben wird, kann der Lösungsweg zunächst als Pseudocode formuliert werden.

Dadurch lassen sich Fehler und Denkfehler oft schon erkennen, bevor programmiert wird.

---

## Beispiel

Aufgabe:

Die größte Zahl aus einer Liste finden.

Zahlen:

```text
4, 8, 2, 9, 1
```

Pseudocode:

```text
größte = erste Zahl

für jede weitere Zahl:
    wenn Zahl > größte:
        größte = Zahl

Ausgabe größte
```

Ergebnis:

```text
9
```

---

## Vergleich: Pseudocode und Java

### Pseudocode

```text
wenn Alter >= 18:
    Ausgabe "Volljährig"
sonst:
    Ausgabe "Minderjährig"
```

### Java

```java
if (alter >= 18) {
    System.out.println("Volljährig");
} else {
    System.out.println("Minderjährig");
}
```

---

## Typische Elemente

### Ausgabe

```text
Ausgabe "Hallo Welt"
```

---

### Eingabe

```text
Name eingeben
```

---

### Bedingung

```text
wenn Alter >= 18:
    Ausgabe "Volljährig"
```

---

### Schleife

```text
solange Zahl < 10:
    Zahl = Zahl + 1
```

---

## Vorteile

- leicht verständlich
- unabhängig von Java, Python oder anderen Sprachen
- hilft bei der Planung von Programmen
- erleichtert die Kommunikation zwischen Entwicklern

---

## Merksatz

> Pseudocode beschreibt die Logik eines Programms, ohne die Regeln einer Programmiersprache einzuhalten.
