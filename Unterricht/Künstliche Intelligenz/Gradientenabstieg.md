
> [!important]
> **Gradientenabstieg (Gradient Descent)** ist ein Verfahren, mit dem ein Modell seine **Gewichte und Biases verbessert**, indem es den Fehler Schritt für Schritt **verringert**.
## Idee

- Modell macht Vorhersage
- Fehler wird berechnet
- Gewichte werden angepasst
- Prozess wird wiederholt

## Ziel

Fehler minimieren

## Wie funktioniert das?

1. Modell macht Vorhersage
2. Fehler wird berechnet
3. Modell schaut:  
    -> „In welche Richtung wird der Fehler kleiner?“
4. Gewichte werden leicht angepasst
5. Wiederholen

---

## Zusammenhang zu vorher

Das ist der nächste Schritt nach:
- Gewichte
- Bias
- Aktivierungsfunktion

Gradientenabstieg sagt:

```
wie diese Werte besser werden
```

---
## Fazit

- Modell lernt durch Fehler
- Gradient zeigt Richtung
- Gradientenabstieg verbessert das Modell Schritt für Schritt
