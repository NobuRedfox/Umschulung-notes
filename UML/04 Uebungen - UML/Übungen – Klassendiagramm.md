# 🟢 Aufgabe 1

Für eine Immobilienverwaltung ergeben sich folgende Anforderungen:

- Eine Immobilie besitzt:
    
    - Adresse
        
    - Wohnfläche
        
    - Kaufpreis
        
- Eine Immobilie kann:
    
    - angezeigt werden
        
    - den Preis pro Quadratmeter berechnen
        
- Ein Eigentümer besitzt:
    
    - Name
        
    - Telefonnummer
        
- Ein Eigentümer kann mehrere Immobilien besitzen.
    

Erstellen Sie ein Klassendiagramm anhand der beschriebenen Anforderungen.

# 🟡 Aufgabe 2

Für eine Bibliothek ergeben sich folgende Anforderungen:

- Ein Buch besitzt:
    
    - Titel
        
    - Autor
        
    - ISBN
        
- Ein Mitglied besitzt:
    
    - Mitgliedsnummer
        
    - Name
        
- Ein Mitglied kann:
    
    - ein Buch ausleihen
        
    - ein Buch zurückgeben
        
- Ein Mitglied kann mehrere Bücher ausleihen.
    
- Ein Buch kann gleichzeitig nur von einem Mitglied ausgeliehen werden.
    

Erstellen Sie ein Klassendiagramm anhand der beschriebenen Anforderungen.

# 🔴 Aufgabe 3

Für ein Steam-ähnliches Spieleportal ergeben sich folgende Anforderungen:

- Ein Benutzer besitzt:
    
    - Benutzername
        
    - E-Mail-Adresse
        
    - Passwort
        
- Ein Spiel besitzt:
    
    - Titel
        
    - Preis
        
    - Genre
        
- Ein Benutzer kann:
    
    - ein Spiel kaufen
        
    - ein Spiel starten
        
- Ein Benutzer kann mehrere Spiele besitzen.
    
- Ein Spiel kann von vielen Benutzern gekauft werden.
    
- Ein Benutzer kann andere Benutzer als Freunde hinzufügen.
    
- Ein Administrator ist ein spezieller Benutzer.
    
- Ein Administrator kann:
    
    - Benutzer sperren
        
    - Spiele entfernen
        

Erstellen Sie ein Klassendiagramm anhand der beschriebenen Anforderungen.
