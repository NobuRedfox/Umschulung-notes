# 🟢 Aufgabe 1

Für einen Geldautomaten ergibt sich folgender Ablauf:

- Kunde steckt seine Karte ein.
    
- Kunde gibt seine PIN ein.
    
- Die PIN wird geprüft.
    
- Ist die PIN korrekt, kann Geld abgehoben werden.
    
- Ist die PIN falsch, wird eine Fehlermeldung angezeigt.
    
- Der Vorgang endet.
    

Erstellen Sie ein Aktivitätsdiagramm anhand der beschriebenen Anforderungen.

# 🟡 Aufgabe 2

Für einen Online-Shop ergibt sich folgender Ablauf:

- Kunde wählt ein Produkt aus.
    
- Das Produkt wird in den Warenkorb gelegt.
    
- Der Kunde entscheidet, ob er zur Kasse gehen möchte.
    
- Falls nein, kehrt er zur Produktauswahl zurück.
    
- Falls ja, gibt er seine Adresse ein.
    
- Anschließend erfolgt die Bezahlung.
    
- Ist die Zahlung erfolgreich, wird die Bestellung bestätigt.
    
- Ist die Zahlung fehlgeschlagen, wird eine Fehlermeldung angezeigt.
    
- Der Vorgang endet.
    

Erstellen Sie ein Aktivitätsdiagramm anhand der beschriebenen Anforderungen.

# 🔴 Aufgabe 3

Für eine E-Learning-Plattform ergibt sich folgender Ablauf:

- Teilnehmer meldet sich an.
    
- Benutzername und Passwort werden geprüft.
    
- Sind die Anmeldedaten korrekt, wird die Kursübersicht angezeigt.
    
- Der Teilnehmer wählt einen Kurs aus.
    
- Lernmaterial wird heruntergeladen.
    
- Anschließend startet der Teilnehmer einen Online-Test.
    
- Der Test wird ausgewertet.
    
- Ist der Test bestanden, wird ein Zertifikat erstellt.
    
- Ist der Test nicht bestanden, erhält der Teilnehmer eine Benachrichtigung.
    
- Der Vorgang endet.
    

Erstellen Sie ein Aktivitätsdiagramm anhand der beschriebenen Anforderungen.
